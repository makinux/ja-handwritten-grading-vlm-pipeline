# 構成によるラベルは観測から識別可能か:日本語手書き数学答案採点 VLM のための合成データとラベル識別可能性

(言語処理学会年次大会 予稿ドラフト v0.1/2026-08-14。著者・所属はプレースホルダ。体裁は学会スタイルファイル適用前の素稿。4 ページ相当・図表 3 点)

---

## 概要(投稿時は本文に統合)

手書き数学答案の採点・誤り診断を行う視覚言語モデル(VLM)の訓練には、誤りの位置・種別・点数が付与された答案画像が必要だが、そのような実データはコスト的に入手困難である。本研究は、解法を実行可能なプログラムとして生成し、誤りをプログラム変異として注入し、決定論的レンダリングで答案画像を合成する **label-by-construction** パイプラインを構築した。1 万件の合成データによる教師あり学習(SFT)で、ゼロショットでは全く創発しない誤り位置特定(IoU@0.5 0.000→0.795)・誤り種別分類(0.000→0.647)を確立し、幻覚率を 31.4% から 0% に抑制した。さらに、構成的には正しいラベルが**観測からは識別不能**でありうるという合成データ特有の失敗モードを実測により発見した(概念的誤解ラベルの 95.6% が機械的誤記ラベルと答案表面で文字列一致)。この診断に基づき、各サンプルの正解を「観測から識別可能な最も細かいラベル」へ再ラベルし、識別不能な事例への下位区分断定を**過剰主張**として罰する評価・報酬を導入した結果、再生成や追加計算なしに種別一致率 0.760→0.964 を達成し、未見問題群での過剰主張率を 90% から 1% に低減した。

## 1 はじめに

記述式数学答案の自動採点には、最終解の正誤だけでなく、途中式のどこで・どの種類の誤りが生じたかの診断が求められる。しかし「誤り位置の座標・誤り種別・対照(誤りなし)画像」を備えた実答案データは存在せず、人手注釈で賄うと 1 万ページで数百万円規模に達する。本研究は、この供給問題を**構成による正解(label by construction)**で解決する:解法を実行可能なステップ列として生成し、誤りを検証可能なプログラム変異として注入し、レンダリングにより全文字の座標を既知とする。ラベルは注釈されるのではなく、構成から導かれる。

本稿の貢献は 3 点である。

1. **パイプライン**:解法プログラム変異・二段ゲート(実行検証/差分封じ込め)・**合成方式逐語化**(LLM は式に接続する説明句のみを生成し、式はテンプレートから機械合成する——式の忠実性が構成的に 100% となる)・LLM による概念誤りオペレータ(誤解の提案を AST ホワイトリスト検証してから変異に変換)・訓練前の報酬敵対的テストからなる完全な実装。
2. **失敗モードの発見**:構成的に正しいラベルが観測から識別不能でありうることの実測。概念的誤解と機械的誤記という異なる生成経路(provenance)が、答案表面では 95.6% 文字列一致しており、モデルの種別一致率 0.760 は「識別不能部分をタイブレークした場合の条件付き上限」0.759 と 3 桁一致した。すなわち未達は能力不足ではなくラベルの識別不能性に起因する。
3. **修正と実証**:各サンプルの正解を観測から識別可能な最も細かい粒度に再定義し(**識別可能粒度ラベル**)、識別不能な事例への細粒度断定を過剰主張として不正解・報酬 0 とする三値設計を導入した。既存データの再ラベルのみ(再生成・GPU 不要)で種別一致率は 0.964 に達し、未見問題群における過剰主張率は 90%→1% となった。「判別できないときに判別できないと言う」挙動は、根拠なく「概念的誤解」と断定しない教育的に望ましい採点者の性質に対応する。

## 2 関連研究

**合成文書データ**:文書理解・OCR 分野では合成レンダリングによる事前学習データ生成が広く用いられる(SynthText [Gupta+ 2016]、Donut の SynthDoG [Kim+ 2022])。これらは転記(読み)の教師信号を合成するのに対し、本研究は誤りの位置・種別・採点という**反実仮想的な細粒度ラベル**を構成により生成する点が異なる。**数学誤り診断**:解答過程の誤りステップ特定はテキスト推論では ProcessBench [Zheng+ 2025]、生徒解答の検証・修正では Daheim+ [2024] があり、手書き数学の VLM 評価では FERMAT [Nath+ 2025](誤り検出・局在化・訂正)や CHECK-MAT [Khrulev 2025] が登場しているが、いずれも**訓練用の座標付き細粒度ラベルの供給**は扱わない。日本語の手書きを含むシーンテキスト理解では JaWildText [Maeda+ 2026] がある。**LLM/VLM による採点**:LLM 採点は essay scoring [Mizumoto+ 2023]・short answer grading [Ferreira Mello+ 2025] で活発だが、基準適合と過剰確信が課題とされる。本研究の過剰主張ペナルティは、選択的予測・棄権付き分類 [Chow 1970; Geifman+ 2017] の考え方を、確信度ではなく**ラベル空間の粒度側**に適用したものと位置づけられる。**合成データの品質**:合成データの factuality・忠実性の課題は整理されている [Liu+ 2024] が、「構成的に正しいラベルが観測から識別不能」という失敗モード——ラベルが観測の関数ではなく生成過程の関数になっている状態——を実測・修正した報告は我々の知る限り存在しない。

## 3 合成パイプライン

**M1 解法プログラム**:中学 1 年数学 2 領域(正負の数・一次方程式)の問題と模範解答を、実行可能なステップ列(例: transpose→divide→answer)として生成する。実行により最終解・全中間値が検証される(ゲート G1a)。

**M2 誤り注入**:誤りはステップ列へのプログラム変異として注入する。機械的オペレータ(移項符号誤り・積の符号落とし・計算ずれ等)に加え、**LLM 概念オペレータ**は「移項しても符号は変わらない」等の誤解を LLM に提案させ、提案式を AST ホワイトリストパーサ(整数定数と加減乗算のみ・長さ制限・eval 不使用)で検証してから変異として適用する。変異後プログラムの再実行と差分封じ込め(変異サイトと因果的影響ノード以外の不変性)をゲート G2 が保証する。対照群(誤りなし)を 30% 混入し、誤りあり/なしの双子ペアはスタイルを共有する。

**逐語化(合成方式)**:答案の文面は LLM で自然文化するが、LLM の出力は「式に自然に接続する説明句」に限定し、**式そのものはステップのテンプレートから機械的に合成**する。これにより式の包含・数値の忠実性が構成的に保証される。プロンプト指示で式を書かせる方式は同一設定でも通過率が 8/20〜16/20 と実行間分散が大きく、合成方式は 20/20 を 2 連で達成したため採用した。逐語化通過率は 1 万件生成時 95% である。

**ゲートと報酬の事前検証**:訓練に先立ち、報酬関数に対する敵対的テスト(欠落・種別列挙・巨大 bbox・転記手抜き等の不正出力 1,000 件が正当出力を上回らないこと)を実施し、実際に 3 件の報酬バグを検出・修正した(最終逆転率 0/1000)。また「テキストのみで誤りが当たる」リーク(AUC 0.652)をプローブで検出し、生成器修正で 0.531 まで除去した。

**規模**:10,000 件(誤り 7,000/対照 3,000)を約 7 時間で生成、全件レンダリング成功。生成 LLM は Qwen3.6-35B-A3B(4bit 量子化、llama.cpp)、計算資源はミニ PC(Ryzen AI Max+ 395、96GB VRAM 割当)1 台である。

## 4 実験 1:ゼロショットから SFT へ

**設定**:Qwen3-VL-2B-Instruct を QLoRA(4bit、言語層のみ r=16)で 9,204 件・1 エポック訓練(NVIDIA TITAN V 1 枚・約 2.5 時間)。入力は答案画像+問題文+模範解答+採点基準、出力は JSON(忠実転記・誤りリスト〔ステップ ID・相対座標 bbox・種別〕・点数)。評価は訓練と分布を共有しない held-out 200 件(ペア単位で隔離)、配備想定の GGUF 8bit 量子化+llama.cpp で実施。

**表 1:ゼロショット→SFT(2B、配備形態、n=200)**

| 指標 | ゼロショット | SFT 後 |
|---|---|---|
| 誤り位置 IoU@0.5 | 0.000 | **0.795** |
| 誤り種別一致(マクロ) | 0.000 | 0.647 |
| 幻覚誤り率(対照への誤り捏造) | 0.314 | **0.000** |
| 検出 BACC | 0.843 | **0.990** |
| 点数完全一致 | 0.345 | **0.935** |

ゼロショットでは 2B/4B/8B のいずれも位置・種別が完全に 0 であり、これらは**合成データでのみ供給可能な教師信号**であることを裏付ける。SFT はこれらを立ち上げ、最大の弱点であった幻覚(誤りのない答案への誤り報告)を対照ペア学習により消失させた。付随して、システムプロンプトの訓練・評価間不一致が配備時性能を大きく損なうこと(点数一致 77.5%→93.5%)を切り分け実験で特定した。

## 5 実験 2:ラベル識別可能性の失敗モードと修正

**発見**:種別一致 0.647〜0.760 は目標(0.85)に未達であり、混同は「概念/移項 vs 記法/移項符号」等の**下位区分ペア内**に集中し、混同方向は実行環境間で反転した。原因を生成データ全件の走査で調べたところ、(i) 概念的誤解オペレータの出力の **95.6%(731/765)が、機械的誤記オペレータの出力と答案表面の文字列レベルで一致**(観測同値)、(ii) 誤解を語る説明句は 0/765(生成器が誤解理由を逐語化に渡していない)、(iii) 積の誤解ペアでは共存領域(q·r<0)の 84.2% が観測同値で、残る「識別可能に見える」領域は競合オペレータが構造的に出現しない**偽の識別可能領域**だった。すなわち下位区分ラベルは**答案の観測可能な性質ではなく生成経路の記録**であり、これを予測ターゲットにしたことが失敗の本質である(label-by-construction 自体は破れていない)。整合性検証として、識別不能部分を多数側にタイブレークした場合の条件付き上限 0.759 は実測 0.760 と 3 桁一致した。

**修正**:各サンプルの種別 GT を「その観測から識別可能な最も細かいラベル」に再定義する(識別可能粒度)。観測同値な事例はファミリ(例: 移項)を GT とし、識別可能な少数事例(全誤りの 1.5%)のみ下位区分を保持する。評価・報酬は三値とする:識別可能粒度と完全一致=正解/GT が下位区分なのにファミリのみ=部分点/**GT がファミリなのに下位区分を断定=過剰主張として不正解・報酬 0**。この再ラベルは既存データに対する決定論的な述語計算のみで実現でき、再生成・再訓練・GPU を要しない。

**表 2:同一データ・同一設定でラベルのみ変更した 2 モデルの比較**

| | 旧ラベル訓練 | 識別可能粒度訓練 |
|---|---|---|
| 種別一致(held-out 200) | 0.760(上限 0.759) | **0.964** |
| 過剰主張率(未見問題群 507 件) | **0.900** | **0.010** |
| 種別ファミリ一致(同上) | 0.31 | **0.806** |
| 検出 TNR/幻覚(同上) | 1.000/0% | 1.000/0% |

旧ラベルのモデルは識別不能な事例の 90% で下位区分を断定する(「判らないのに概念的誤解と言う」)のに対し、識別可能粒度で訓練したモデルはこれを 1% に抑えつつ、識別可能な信号は保持した。教育応用において、根拠のない誤り原因の断定は誤った指導介入を招くため、この性質は実用上の要件である。

## 6 限界

本結果は合成描画(フォントレンダリング)内での実証であり、実筆跡への転移(sim2real)は今後の字形バンク収集を要する。識別可能粒度訓練は 3 シード(42/43/44)で反復し、held-out 200 における種別一致は 0.976±0.010(本文の 0.964 は最小値)、IoU@0.5 は 0.950±0.016、検出(TPR/TNR)・点数・転記はシード間分散ゼロであった。一方、未見問題群(507 件)での新旧ラベル比較は各 1 run であり、検出率差(0.968 vs 0.874)には訓練分散が混入しうる(シード別の未見セット評価は今後の課題。種別の質的差である過剰主張 90%→1% は構造由来で頑健)。下位区分ラベルの復活には、反復一貫性を観測できる実データ(同一書き手の複数答案)が必要であり、これは技術条件ではなく収集上の外部依存である。教員間一致の実測は進行中であり、人手参照系の評価は未実施である。

## 7 おわりに

細粒度・反実仮想ラベル付き答案データを構成により合成し、2B の小型 VLM で誤り位置・種別・採点能力を確立した。あわせて、合成データのラベルが「構成的に正しいが観測から識別不能」でありうるという失敗モードを実測し、識別可能粒度への再ラベルと過剰主張ペナルティという一般性のある処方を示した。コードは公開予定である。

### 付録 A: 実際の生成例(gen10k 実データ、sample_id: c000-math-g7-lin-000008)

**問題**: 次の方程式を解きなさい。 4x − 5 = −10(配点: 立式 3・変形過程 4・最終解 3)

| | 模範解答(gold) | ミュータント(概念/移項を s2 に注入) |
|---|---|---|
| s1 | 与えられた方程式は、4x − 5 = −10 | 与えられた方程式は、4x − 5 = −10 |
| s2 | 両辺に 5 を足して、4x = −10 **+** 5 | 両辺に5を足して、4x = −10 **−** 5 |
| s3 | 右辺を計算すると、4x = −5 | 右辺を計算して、4x = **−15**(伝播) |
| s4 | 両辺を 4 で割って、x = −5/4 | 両辺を4で割って、x = **−15/4**(伝播) |

**構成から導かれる GT**: 誤り = {type: 概念/移項(識別可能粒度では「移項」)、mutation_site: s2、span: 文字 18–19、bbox: [839,352]–[863,372] px、propagates: s3, s4}/点数 = 3/10(立式のみ充足をルーブリック関数で決定論的に算出)/対照ペア(-e0)= 同一スタイルの誤りなし版。注入は「+ 5」→「− 5」の 1 文字であり、説明句・下流の式は G2 が封じ込めを保証しつつ因果的にのみ変化する。この例が図 2 の観測同値の実例でもある(機械オペレータ op-transpose-sign も同一の表面「4x = −10 − 5」を生む)。
