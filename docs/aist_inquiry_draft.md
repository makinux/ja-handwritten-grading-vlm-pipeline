件名: ETL文字データベースの利用条件に関するお問い合わせ(機械学習での派生的利用について)

ETL文字データベース ご担当者様

お世話になっております。〔会社名〕〔部署〕の〔氏名〕と申します。
弊社では手書き文字認識に関連する研究開発を行っており、ETL文字データベース
(主に ETL9G/ETL9B)の利用を検討しております。

2025年3月28日改定の利用規約を拝読し、データベースの利用が無償で認められて
いること、データそのものの再配布が禁止されていることは理解いたしました。
その上で、規約に明示されていない以下の3点の可否について、ご見解を
伺えますでしょうか。

1. **学習済みモデルの扱い**
   ETL の文字画像を学習データの一部として機械学習モデル(画像生成モデルの
   軽量適応重み等)を作成した場合、その学習済みモデル(重みファイル)を
   弊社製品・サービスに組み込むこと、または社外へ提供することは可能で
   しょうか。

2. **合成画像の社外提供**
   ETL の文字画像(字形)を文書レイアウト上に合成配置して作成した合成文書
   画像を、(a) 弊社の機械学習モデルの学習・評価データとして社内利用する
   こと、(b) 研究発表・製品の一部として社外に提供することは、それぞれ
   規約第5条(データ自体の再配布禁止)との関係でどのように整理されます
   でしょうか。

3. **外部計算資源での処理**
   ダウンロードしたデータを、弊社が契約する外部クラウドの計算資源
   (GPU サーバ等)へアップロードして機械学習の処理に用いることは可能で
   しょうか(第三者への提供は行わず、処理後は削除いたします)。

利用に際しては、規約第4条の出典表記(Electrotechnical Laboratory, Japanese
Technical Committee for OCR, ETL Character Database, 1973-1984)を遵守いたします。

お忙しいところ恐れ入りますが、ご回答のほどよろしくお願いいたします。

〔署名〕
