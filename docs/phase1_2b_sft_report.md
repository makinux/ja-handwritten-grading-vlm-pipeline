## 主要な発見

1. **ゼロショット全滅だった細粒度能力が立ち上がった。** 位置特定 IoU@0.5 0.007→0.731、
   種別分類 0→0.747。反実仮想・文字座標 GT ラベルの学習可能性が実証された
   (設計 §1.4「唯一の細粒度・反実仮想ラベル路線」の in-distribution 実証)。
2. **幻覚が消えた(0.561→0.000)。** 対照(誤りなし)ペアを含むペア生成原則が SFT だけで
   効く。ゼロショット最大の弱点(TNR)が対照学習で解消される見込みが立った。
3. **採点が完全一致 1.00。** ルーブリック条件付き採点(配点サンプリング)が形式ごと
   学習された。ゼロショットの不安定さ(モデル規模と単調でない)は訓練で標準化された。
4. **残る弱点は隣接クラス混同の 2 種のみ。**「概念/移項」13 件中 12 件を「記法/移項符号」
   と誤分類、「計算/符号」3 件全てを「概念/符号・乗算」と誤分類。いずれも誤りスパンの
   見た目がほぼ同一で、説明句(逐語化の誤解の語り)の読解が必要な区別。対策候補:
   フルデータ(9,204)訓練での該当クラス増量/クラス定義の再検討(統合 or 判別特徴の明示)。
5. **TITAN V 単機で 1 サイクル 65 分。** 2B 縮小構成の反復実験は dev216 で十分高速
   (Kaggle 想定 4-6h → 実測 1h)。フルデータでも ~2.5-3h/サイクルの見込み。

## 追記: フルデータ第2ラウンド(9,204 件、同日実施)

TRAIN_LIMIT=9204(全訓練データ)で同一構成の第 2 ラウンドを実施。訓練 149.1 分
(loss 0.92→**0.059**)+評価 16.5 分。before 評価は第 1 ラウンドと**全指標完全一致**
(ハーネスの決定性を確認)。

| 指標(after) | 3,000 件 | **9,204 件** |
|---|---|---|
| 転記 CER(平均) | 0.0000 | **0.0000** |
| TNR/BACC/幻覚 | 1.000/1.000/0.000 | **1.000/1.000/0.000** |
| 点数完全一致/±1 | 1.000/1.000 | **1.000/1.000** |
| 誤り位置 IoU@0.5 | 0.731 | **0.948**(134 件中 IoU<0.5 は 7 件のみ) |
| 誤り種別一致(マクロ) | 0.747 | **0.760** |

- **位置特定はデータ量で大きくスケールした**(0.731→0.948、目標 0.70 を大幅超過)。
- **種別の残課題は「移項ファミリ内の下位区分」に収斂した。**「概念/移項」は 1/13→6/13 と
  改善する一方、「記法/移項符号」が 20/22→13/22 と逆方向の混同が発生(双方向化)。
  ただし**ファミリレベルでは 35/35=100%**(gt が移項系の全サンプルで、予測も移項系の
  いずれか)。「計算/符号」(n=3)も全て符号系隣接クラス「概念/符号・乗算」への混同。
  → モデルは誤りの所在とファミリを完全に特定しており、下位区分(概念的誤解 vs 記法ミス)が
  **答案表面から観測可能か**というタキソノミ設計の問題に帰着する。参考値: 移項 2 クラスを
  統合した場合のマクロ ≈0.85、符号系(計算/符号+概念/符号・乗算)も統合すれば ≈0.97。
- 対応候補: (a) 評価タキソノミをファミリ粒度へ改定(観測可能性基準)、(b) 逐語化の
  説明句に下位区分の判別特徴を強制(生成側の対処)、(c) 現行維持で sim2real 後に再判定。
  **設計判断事項として次回レビューに付す。**

成果物: dev216 `~/ja-grading/out/dev216-full/{lora_adapters,eval_results.json}`、
ローカル `out/dev216_sft/eval_results_full.json`。

## 追記2: 配備経路検証 — llama.cpp 同一ハーネス再評価(同日)

フル訓練済み LoRA をマージ(dev216 CPU)→ GGUF F16(convert_hf_to_gguf.py、b10255)→
Q8_0 量子化 → EVO-X2 llama.cpp(Vulkan、ポート 8082、mmproj は既存 Q8 を再利用)で
サーブし、**ゼロショット表と同一プロトコル**(seed77・n=200・`--coords relative`・
temperature 0)で再評価。5.9 秒/件、parse 失敗 0。評価ハーネスの座標モードは
タスク J(db24fad)で追加(pixel モードは HEAD と byte 一致=後方互換)。

| 指標 | 2B ゼロショット | **2B SFT 後(llama.cpp Q8)** | 参考: HF fp16 直接 |
|---|---|---|---|
| 幻覚誤り率 | 0.314 | **0.059** | 0.000 |
| 検出 TNR | 0.686 | **0.941** | 1.000 |
| 検出 BACC | 0.843 | **0.964** | 1.000 |
| 誤り位置 IoU@0.5 | 0.000 | **0.707** | 0.948 |
| 誤り種別一致(マクロ) | 0.000 | **0.656** | 0.760 |
| 点数完全一致/±1 | 0.345/0.385 | **0.775/0.785** | 1.000/1.000 |
| 転記 CER(平均) | 0.024 | 0.019(中央値 0) | 0.000 |
| 検出 TPR | 1.000 | 0.987 | 1.000 |
| over-correction 率 | 0.087 | 0.101 | —(本ハーネスのみ計測) |

- **結論 1: 配備経路は成立し、ゼロショット表はこの列で正式更新できる。** 同一サンプル・
  同一ランタイム・リークなし(seed77 の 200 件は SFT 分割で test に隔離済み)の比較で、
  幻覚 31.4%→5.9%、BACC 0.843→0.964、IoU 0→0.707、種別 0→0.657、点数 34.5%→77.5%。
- **結論 2: HF fp16 直接推論との差が存在する**(IoU −0.24、点数 −0.225 等)。切り分け候補:
  (a) **システムプロンプト不一致**(SFT は system なしの messages で訓練、本ハーネスは
  SYSTEM_PROMPT を付与)——最有力・50 件の ablation で検証可能、(b) Q8_0 量子化
  (言語+mmproj 視覚塔とも)、(c) 画像前処理差(HF は max_pixels 縮小、llama.cpp は
  mmproj ネイティブ)、(d) 評価サブセット差(seed77 層化 vs test 先頭 200)。
  温度は両者 0 で共通(要因外)。
- 種別の混同は本ハーネスでも移項ファミリ内に収斂(方向は逆転: 概念/移項 0.94、
  記法/移項符号 0.00)。下位区分の不安定性がランタイムを跨いで再現し、
  **タキソノミ粒度の設計判断**の必要性を補強。「表記/符号落とし」も 0.33 に低下——
  符号系の微細な視覚特徴が配備経路の変換((b)/(c))に最も敏感である示唆。
- over-correction は 10.1% と SFT 後も残存(ゼロショット 8.7% と同水準)。忠実転記の
  強化は SFT だけでは不足で、報酬設計(RL/DPO)または訓練データ側の対処が次の論点。

## 追記3: 配備ギャップ ablation 完結(2026-08-14)

追記2 のギャップ要因候補を分解実験で判定した。全 run は llama.cpp Q8/Vulkan(dev187)、
`--coords relative`、temperature 0。

| Run | 構成 | 幻覚 | BACC | IoU@0.5 | 種別 | 点数一致 |
|---|---|---|---|---|---|---|
| A0 | Q8・system**有**・n50 seed77 | 6.7% | 0.967 | 0.800 | 0.674 | 0.720 |
| A2 | **F16**・system有・n50 seed77 | 6.7% | 0.967 | 0.800 | 0.674 | 0.700 |
| A1 | Q8・system**無**・n50 seed77 | **0%** | 0.971 | **0.848** | 0.615 | **0.860** |
| D2 | Q8・system有・n50 **seed13** | 30.0% | 0.850 | 0.725 | 0.795 | 0.600 |
| **公式更新** | **Q8・system無・n200 seed77** | **0.0%** | **0.990** | **0.795** | 0.647 | **0.935** |

判定:

1. **(a) システムプロンプト不一致が主因(確定)。** SFT は system なしの messages で
   訓練されており、ハーネス側の SYSTEM_PROMPT 付与が分布シフトだった。除去(タスク K の
   `--system off`)により幻覚 5.9%→0%、点数 77.5%→93.5%、IoU 0.707→0.795、CER
   0.019→0.007、over-correction 10.1%→**4.0%** と全面回復。
   **SFT モデルの配備・評価プロトコルは「system メッセージなし」で確定。**
2. **(b) 量子化は無罪(確定)。** A0(Q8_0)と A2(F16)は指標がほぼ完全一致。
   Q8_0 を配備量子化として維持。
3. **(d) 小標本の揺れは大きい。** seed13 の n=50 では幻覚 30% など大きく変動
   (対照 ~15 件では 1 件の差が 6.7pt 動く)。**n=50 は方向判定のみ、公式値は n=200**。
4. **(c) 画像前処理差が残差の主候補。** 公式 IoU 0.795 vs HF fp16 直接 0.948 の残差は、
   HF(max_pixels 縮小)と llama.cpp mmproj(ネイティブ解像度)の前処理差+評価
   サブセット差に帰属する見込み(必要になれば HF 側での seed77 評価で切り分け可能)。

**§7 仮目標への到達状況(配備形態・n=200・リークなし)**: TNR 1.000 ✅/幻覚 0% ✅/
IoU@0.5 0.795 ✅(≥0.70)/点数完全一致 0.935 ✅(≥0.80)/種別 0.647 ✗(≥0.85、
タキソノミ粒度の設計判断事項)。
