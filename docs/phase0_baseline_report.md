## 主要な発見

1. **転記と誤り検出(TPR)は現行描画では飽和している。** プレースホルダフォント
   (UD デジタル教科書体等)による描画は実質「印刷文字」であり、ゼロショット 8B が
   CER 0.003・TPR 1.0 を達成する。over-correction 0(8B/4B)・ミュータント行の
   忠実転記から、プロンプト中の模範解答の丸写しではなく実際に画像を読んでいる
   ことを確認済み。→ **「読む」難度は字形バンク(統合収集プログラム)の導入で
   初めて生まれる。** sim2real 評価(書き写しセット)が本丸であることの定量的裏付け。
2. **検出の実際の弱点は対照側(幻覚)。** TNR は 0.92/0.84/0.69 とモデル規模で
   劣化し、2B は誤りのない答案の 31% に誤りを捏造する。誤りなし対照群への
   偽陽性罰(報酬設計)と TNR 重視の運用はパネル議論のとおり正しい焦点だった。
3. **位置特定(bbox)と種別分類(タキソノミ)は全モデルで完全にゼロ。**
   ピクセル座標の誤りスパン・誤り分類は、ゼロショットでは全く出てこない
   **正真正銘の未学習能力**であり、本データセットの反実仮想・細粒度ラベルが
   埋める価値そのもの(§1.4 の「唯一の細粒度・反実仮想ラベル路線」の実証)。
4. **採点(ルーブリック適用)はゼロショットでは不安定。** 4B(71%)> 8B(26%)
   という規模逆転は、採点手順の指示への従い方の個体差(8B は独自の減点方針を
   取りがち)であり、能力の単調性がない=**訓練で標準化すべき挙動**であることを示す。
5. 2B にのみ over-correction が 8.7% 出現——小型モデルほど「あるべき答案」への
   書き換えが起きる。忠実転記報酬(over-correction 罰)の設計が 2B 縮小構成の
   訓練でそのまま効く見込み。
