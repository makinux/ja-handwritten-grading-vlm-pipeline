## 所見

1. **三値設計(過剰主張ペナルティ)の実証**: 旧モデルは識別不能な標本の 90% で下位区分を断定する(「判らないのに概念的誤解ですと言う」)。識別可能粒度で訓練した新モデルはこれを 1% に抑えた。教育的に有害な断定の除去がラベル改定の主目的であり、達成された。
2. **層 1 下限条件が発動**: 新モデルのファミリ 7 クラス平均 0.806 < 0.90 → 3 層ゲートの規定どおり**数値閾値は未設定のまま原因調査へ**。test 内評価(0.964)との乖離要因候補: (i) fresh 問題群への汎化ギャップ(最有力——test.jsonl は同一生成プール内)、(ii) 配備経路(Q8/前処理)、(iii) 層化による難クラス増量(計算/加減 0.53・符号落とし 0.68 が弱い)。
3. **検出・位置・点数は旧モデルが上**(TPR 0.968 vs 0.874 等)。同一条件 1 run ずつの比較であり、ラベル変更の副作用か訓練分散かは**未分離**(要: 追加シード訓練 1 本=~3h で分散推定)。種別の質の差(過剰主張 90%→1%)は構造由来で頑健。
4. 下位区分 GT(17 件)は新モデル 0.000——訓練中の被覆 1.1% では学習されない。監査枠の位置づけどおり。旧モデルの 概念/移項 1.000 は n=1。
5. TNR 1.0・幻覚 0%・over-correction ~4% は両モデル・fresh データで堅牢。
