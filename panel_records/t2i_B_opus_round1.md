# Round 1 回答 — パネリストB(第一原理・外側視点)

## 0. 明確な反対(結論先出し)

**反対する中心的主張:「配管と座標保存性を先に検証してから GPU 費用を使う(Stage A を Phase 0 で並行実施する)という順序が正しい」。**

私の立場は逆である。**Stage A/C(diffusion 層)は Phase 0 から外し、「外観ギャップが採点KPIの主要項か」を測る無料の実験に賭け金を移すべき**。理由は三つ:

1. 配管(パッチ分割・座標帳簿・ドリフト補正・検品)は **diffusion 層が生き残った場合にのみ必要な資産**であり、「FT と無関係に必要」という記述は誤り。ETL グリフバンク方式(Stage B')は座標を構成的に持つので、パッチ往復・位相相関・CER 棄却のいずれも不要である。つまり「先に通す配管」は diffusion 専用の埋没費用になる。
2. 配管を先に作ると、Go/No-Go の No 側が政治的に選べなくなる(埋没費用による意思決定の硬直化は、この種の計画が失敗する最も一般的な経路)。
3. 判定ゲートが**全部内部整合性ゲート**(CER・bbox ずれ・双子一致)で、**下流効用ゲートが一つもない**。この設計書は「リアリズムを上げる」ことの妥当性を一度も検証せずに、リアリズムを上げる方法の最適化に入っている。

さらに強い反対を一点:**Stage C は原理的に情報量ゼロである**(§3)。

## 1. sim2real ギャップの成分分解と、diffusion 層が埋める部分

事実(定義上明らか):最終KPIは「実答案での採点精度」。採点は〔読字 → 正誤判断 → 誤りスパン局在〕の合成。

推測(私の分解、確信度 80%):実答案とのギャップは以下の成分に分かれ、寄与は概ねこの順:

| 成分 | 内容 | diffusion 層は埋めるか |
|---|---|---|
| (d) **内容分布** | 実生徒の誤答・部分解・無解答・的外れ解答・言い訳文の分布 | **埋めない**(むしろ無関係) |
| (c) **行動的レイアウト** | 取り消し線、挿入キャレット、矢印、上書き、消しゴム跡、欄外はみ出し、末尾で字が縮む、行が斜行、二重線で書き直し | **埋めない** |
| (b) **字形の崩れ** | 実筆者の乱雑さ・略字・続け書き | ETL が一部、diffusion は「Qwen の手書き多様体」という**別の狭い分布**を足すだけ |
| (a) **筆致テクスチャ** | インク濃淡・筆圧・かすれ | **埋める(ここだけ)** |
| (e) **撮像** | スキャナ/スマホ・斜行・影・JPEG・裏写り | 撮像層の担当(diffusion 不要) |
| (f) **答案様式の多様性** | 実際の答案用紙レイアウトのばらつき | レンダラの担当 |

**第一原理での主張(確信度 72%):採点VLMの学習に必要なのは「リアリズム」ではなく「不変性(invariance)」である。** sim2real の外側視点(ロボティクスの base rate)では、フォトリアリズム投資よりドメインランダム化が勝つ事例が繰り返し観察されてきた。diffusion スタイル変換は**単一モデルの様式に収束した狭いリアリズム**を注入するため、不変性の獲得という目的に対しては、手書きフォント多数 × ETL 字形 × 弾性変形 × 強い撮像ランダム化という**広い被覆**に劣る可能性が高い。すなわち diffusion 層は「最も高価で、最もリスクが高く、KPIへの寄与が最も間接的な」成分に投資している。

**反証条件(費用ゼロ、CPU、~2日)**: 同一の小型採点モデル(Qwen3-VL の小サイズを LoRA、EVO-X2 または Kaggle)を3系統の学習データで訓練 — (a) 印刷フォント1種+撮像層、(b) 手書き系フォント20種+ジッタ+弾性変形+撮像層、(c) ETL9B グリフバンク+撮像層 — 各3,000頁。評価は §2 の実答案100枚。**(a)→(c) の項目単位採点精度の差が 10pt 超なら外観は主要項であり、私の主張は棄却**。差が 3pt 未満なら diffusion 層は Phase 0 で不要が確定する。追加費用: 0円。

## 2. 見落とされている工程 — 計画に「測る道具」がない

事実(文脈記載):sim2real 評価は存在せず、実答案1,350枚は謝金未確保で未実施。

これがこの計画の構造的欠陥である。**リアリズム改善計画が、リアリズム改善の効果を測る計器を持たないまま、改善手法の詳細設計に入っている。** 同種計画の典型的失敗経路(base rate、確信度 85%):「リアリズムのトレッドミル」— 停止条件がないため、外観への投資が無期限に続き、KPI への寄与は最後まで測られない。この設計書の「未決」4項目はすべて diffusion 分岐のパラメータであり、**「そもそも要るのか」が未決リストに入っていない**のが症状。

**最も安価で最も価値の高い代替行動(機会費用の核心)**:1,350枚の謝金を待たず、**社内で実答案を100枚作る**。社員10名×10枚、印刷済み答案用紙に手書き、スマホ撮影。謝金0円、半日。項目数 ~1,000 で項目精度の95%CIは概ね ±3pt であり、上記 10pt 級の効果を検出するには十分。**この一手が、設計書に書かれたすべての diffusion 作業より KPI 期待値が高い**(確信度 80%)。

同時に無料で走る診断:Qwen3-VL に実答案100枚と合成答案100枚を転記させ CER を比較。実 25% 対 合成 3% のような桁差が出れば「読字が崖状に壊れている」=外観が主要項の証拠(§6 参照)。

## 3. Stage C は原理的に情報量ゼロ(最も強い攻撃)

設計書は「ペアデータは自給できる:入力=フォントレンダ、出力=ETL グリフバンク合成」を**強み**として提示している。第一原理では**これは致命的欠陥**である。

- 決定的手続き `P`(自前レンダラ)が生成した出力を教師として、写像 `A → P(A)` を diffusion に学習させても、得られるのは `P` の近似である。**`P` を既に所有している以上、リアリズムの純増はゼロ**(確信度 90%、これは情報論的にほぼ定義)。
- 実際に増えるのは(i) 近似誤差、(ii) 事前分布から漏れ出す「もっともらしさへの平滑化」だけ。(ii) は本物の追加情報だが、それは**Stage A のゼロショットが既にテストしている中身と同一**であり、より安価。したがって **Stage C は Stage A に支配される(dominated)**。
- Stage C が意味を持つのは出力側が `P` の外にある場合、すなわち **Kondate(50万円)を買った場合のみ**。つまり Stage C は「予算確保後の条件付き工程」ではなく、**「50万円確保後にのみ存在する工程」**。設計書は条件を安く見せている(数百〜千円台のスポット費用として提示)。

**反証条件(Kaggle 無料、~3時間)**: Stage A のゼロショット出力と、Stage C 相当(自給ペア LoRA)の出力を、同一入力に対して比較。人間または Qwen3-VL による2択リアリズム判定100組で、**Stage C 出力が Stage A 出力に有意に(60:40 超で)勝つなら私の主張は棄却**。ただしこの検証自体が LoRA 学習(数百円)を要するので、先に安価な代理:Stage B' 出力と Stage A 出力の2択判定で「事前分布の寄与」を切り分ける(費用0)。

## 4. 「検品ループがあるから大丈夫」の解体

設計書の3層防御を評価する:

**防御(2)位相相関による bbox 補正は数学的に不適合(確信度 80%)。** スタイル変換で生じるずれは**非剛体の変形場**(ベースライン揺れ、字間再配置、字幅変化)であり、位相相関が推定できるのは**大域的平行移動という剛体1成分のみ**。文字単位 bbox GT を守るには文字ごとの対応が必要で、それを得るには文字検出器が必要 — その瞬間に「label-by-construction」は回答領域について放棄され、**設計原則1を守るために導入した方式が原則1を壊す**。なお「数px は IoU なので許容」は部分的に正しい(誤りスパン級の IoU 0.5 判定なら数px は無害)ので、ここは条件付きで譲る。問題はずれが**系統的で誤りスパンと相関する**場合。

**防御(3)検品ループは無作為フィルタではなく、選択バイアス装置である(確信度 85%)。**
- CER 棄却は「現行 OCR が読めなかったサンプル」を落とす。結果、生き残るのは**判定器が読みやすい手書き**だけ。求めていた乱雑さの裾を、まさに狙って除去する。データセットの上限が判定器の能力に固定される(自己蒸留の天井)。
- 生成器 Qwen-Image-Edit と判定器 Qwen3-VL は近縁の視覚事前分布を共有しており、**盲点が相関**する。判定器が読める崩れしか残らない、という偏りが二重に効く。
- さらに悪い:編集モデルの事前分布は「もっともらしい正しい文字」に向かう。**意図的に間違えた漢字や崩れた誤答を「修復」する**傾向があるため、棄却が**誤りサンプル側に集中**する。結果、誤りあり答案が体系的に「軽い誤り」に偏る = 採点学習の中核ラベル分布が歪む。

**最も危険なリスク(確信度 65%、ただし影響は最大)**:双子は誤りスパンだけが違うので**条件画像が異なる**。diffusion は条件画像に対して連続ではないため、「同一 seed = 同一スタイル」は成立しない。誤りを含むパッチだけが系統的に異なる扱いを受ければ、**モデルは内容ではなくレンダリング由来の痕跡から誤りを検出できる**ようになる。内部指標(CER も bbox も通る)では検出されず、実答案でのみ崩れる。ショートカット漏洩は合成データ計画の最頻死因の一つ。

**反証条件(Kaggle 2時間、無料)**: 双子200組をゼロショット変換し、(i) 誤り側/清書側の棄却率差、(ii) **誤りスパン領域をマスクした残り領域のみ**から誤り側か清書側かを当てる軽量識別器(小CNN or 低次統計+ロジスティック回帰)の AUC。**AUC ≈ 0.5(±0.03)かつ棄却率差 2pt 未満なら漏洩の主張は棄却**。AUC > 0.6 なら Stage A は No-Go。

## 5. 規模の算術 — 条件付きにされているのが間違った工程

設計書は **LoRA 学習(安い)を条件付き工程にし、30万頁の推論(高い)を無条件の本線アーキテクチャにしている**。順序が逆。

推測(オーダー見積、確信度 75%):1頁あたり回答パッチ8〜12枚、Lightning 4-step + Q4 で T4 級では楽観的に 1〜3秒/パッチ。30万頁 = 240〜360万パッチ → **700〜3,000 GPU時間**。Kaggle 週30時間では **24〜100週**。スポットでも(棄却再生成込みで)数百〜数千ドル規模になり得る。「予算ゼロ運用と整合」する段階計画という記述と 30万頁目標は両立しない。diffusion 層は本質的に**少量高級品の工程**で、量産アーキテクチャの本線に置かれている。

**反証条件(Kaggle 30分、無料)**: 実パッチ寸法での秒/パッチを実測し、パッチ数/頁を掛けて総 GPU 時間を出す。**総計 150 GPU時間未満なら私の主張は棄却**。

## 6. 「解けたと称しているがずれた問題」

- 設計書が精緻に解いたのは **「生成でラベルを壊さない方法」**。これは4番目に重要な問題。1番目は「どの分布に合わせるべきか、そしてそれはKPIを動かすのか」。
- Stage B' の弱点として挙がる「字間・ベースラインの不連続感」は **diffusion の仕事ではなく手続き的に解ける**:筆者ごとのベースラインスプライン、傾き・サイズドリフト、字間ノイズ、グリフマスクへの弾性/TPS 変形、モルフォロジー+テクスチャ合成によるインク滲み。すべて CPU・ラベル完全保存・追加費用ゼロ。**設計書は「現行 PIL+フォント」という藁人形をベースラインに diffusion を比較している**。公正なベースラインは「フォント多数+ETL+弾性変形+強撮像層」。
- 手描き図形: matplotlib xkcd は妥当だが、xkcd 揺らぎは**漫画的揺れ**で、生徒図の実相(比率が狂う、曲線が閉じない、二度書き、定規で引いたが傾いている)ではない。ここも(c)行動的リアリズムの問題で、手続き的に書くべき。
- ETL の弱点として「1970-80年代の丁寧な楷書寄り」が正しく認識されているが、これは **diffusion では直らない**(Qwen の事前分布も現代日本人生徒の乱雑さを持たない)。直せるのは実データのみ。ETL 筆者は**200名 = スタイル母集団が極小**で、diffusion 層も母集団を1つ足すだけ。連続的多様性は変形パラメータの連続サンプリングでしか得られない。

## 7. 法務リスクの非対称な扱い(工程の見落とし)

設計書は Kondate について「合成データ社外配布は要交渉」と書きつつ、**ETL については同じ問いを立てていない**。ETL 規約の禁止事項が「データ自体の再配布」なら、**ETL のビットマップを1:1で逐字合成した30万頁**は、統計的抽象ではなく原データの逐語的埋め込みであり、社外に出る局面で派生的再配布に当たる可能性がある(確信度 45%、法的判断は私の担当外)。しかも ETL は Stage B' の**主素材=全体の土台**。無料のメール1本で解ける最高分散の未決事項が「未決」に留め置かれているのは工程順序の誤り。**AIST 照会は今日出すべき最初のタスク**であり、Stage A の閾値決めより優先度が高い。

## 8. 私の議論の最も弱い点

**「外観ギャップは従属項」という前提は、採点が読字に対して崖(cascade)構造を持つ場合に反転する。**

採点精度は読字精度に**ハードに従属**する — 読み間違えたら判断の質は無意味になる。そして日本語手書き漢字の VLM 読字は英語より明確に弱い。もし実答案が Qwen3-VL の日本語手書き読字が崩壊する側に位置しているなら、外観は**主要項どころか唯一のボトルネック**になり、私の「不変性 > リアリズム」論は連続的なトレードオフではなく閾値問題に置き換わって崩れる。

**これを崩す観測(無料)**:実答案100枚と合成100枚の Qwen3-VL 転記 CER 比較。実 CER が合成の5倍以上(例 25% 対 3%)なら、外観・可読性ギャップは大きく、外観投資一般は正当化される。

ただしその世界でも投資順序は **実データfine-tune > 手続き的変形・撮像層 > diffusion** のままだと私は考える(確信度 70%)。反転するのは「外観に投資すべきか」で、「diffusion に投資すべきか」ではない。

## 9. 私の対案(要旨)

1. **今日**: AIST 照会送付(0円)。社内実答案100枚の収集(0円、半日)。
2. **今週**: Stage B'(ETL グリフバンク)+ 手続き的乱雑さ(弾性変形・ベースラインスプライン・サイズドリフト・インク滲み)+ 撮像層ランダム化の強化。すべて CPU・ラベル完全保存。
3. **来週**: §1 の3系統アブレーション(印刷フォント / 手書きフォント多数 / ETL)を実答案100枚で評価。**これが diffusion 分岐の唯一の正当なゲート**。
4. **ゲート通過時のみ**: Stage A ゼロショットを、§4 の双子漏洩テストと §5 のスループット実測を**合格条件に含めて**実施。
5. **Stage C(自給ペア LoRA)は削除**。Kondate 購入が決まった時にだけ復活させる。
6. 行動的リアリズム(取り消し線・挿入・上書き・欄外・無解答)の手続き生成器を、diffusion より先に着手。KPI 寄与の期待値がはるかに高く、費用は同じくゼロ。
