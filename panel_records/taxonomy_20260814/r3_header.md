# ラウンド 3: 最終立場

あなたはこの設計パネルのパネリストである(最終ラウンド)。下に「あなたへの批判(相手のラウンド 2)」と「ファシリテータ検証済み事実の追補(V6〜V9)」が続く。あなたの最終メッセージが討論記録としてそのまま保存される。前置き不要。日本語。

## 指示

1. **正当な批判には理由付きで譲歩せよ**(社会的譲歩ではなく、論拠による譲歩のみ)。
2. **生き残る主張は理由付きで防衛せよ。**
3. 確信度を変えた場合、**それを動かした具体的論拠を必ず明記**せよ(説明なしの全面転向は不可)。
4. 残余不確実性を明示し、各中核主張に較正済み確信度と実行可能な反証条件を付けよ。
5. D1〜D5 の最終立場を、裁定者がそのまま採用できる**決定文の形**で書け(「〜すべき」ではなく「〜する。条件は〜」)。
6. 相手と合意に達した項目は簡潔に列挙し、**残る真の対立**があれば「何の証拠があれば決着するか」を付して明示せよ。
