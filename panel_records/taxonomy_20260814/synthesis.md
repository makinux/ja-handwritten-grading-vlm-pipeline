## 決定(D1〜D5、設計書反映用)

**D1(タキソノミ)**: `errors[].type` の GT を「観測から識別可能な最も細かいラベル」へ再ラベル(移項: 曖昧 1,564→ファミリ/概念/移項 34 のみ下位区分。積: 曖昧 362+偽識別 425→ファミリ/概念/符号・乗算 68 のみ)。旧下位区分の混同行列は「provenance 割当監査」として報告可(モデル品質診断と呼ばない)、条件付き ρ・識別可能率・クラス別 n の 3 点併記義務。`evidence_basis∈{explicit,unknown}` 追加(explicit は実答案人手のみ、合成生成禁止、基底率 <15% なら削除)。`repeated` は集約出力側。
**D2(報酬)**: 階層部分報酬は撤去。識別可能粒度採用時に三値へ(完全一致=満点/識別可能なのにファミリのみ=明確に低い部分点/識別不能なのに下位区分=過剰主張 0)。
**D3(深刻度)**: 原因由来 sev を GT・報酬から除外、結果由来(最終解影響・伝播・符号のみ)へ再定義、それまで unknown。RL 重み使用の可否を先に確定。一律 sev2 は不採用。
**D4(実装)**: クラス統合でも G3 再生成でもなく領域単位再ラベル(実施済み・述語は決定論的)。③は文字列一致分を ambiguous として分母除外、ファミリ統合しない。下位区分被覆率(現状 1.5%)併記義務。
**D5(出力契約)**: type は要素局所・識別可能ラベルのみ。学習者集約診断は範囲外として先送り、ただし設計書に「復活は中学生書き手調達(collection_plan.md:50、所有者・期日未定)に律速」と明記。
**閾値(3 層)**: 層 0=データ健全性(識別不能標本への下位区分 GT=0 件、自動検査)。層 1=参照(HF)は n=400 測定後に設定(下限条件: 0.90 未満なら原因調査へ)。層 2=配備(llama.cpp)はランタイム差 ≤0.05+回帰ガード(Wilson 下限)。現状: HF 0.970 ✓ 下限通過/差 0.100 ✗(主因は符号落とし 0.333=配備経路の視覚劣化でタキソノミ外、ablation 済みの既知問題)。数値閾値の設計書記載は n=400 測定まで凍結。
