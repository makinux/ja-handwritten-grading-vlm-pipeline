## 1. A の批判への裁定

### 1.1 全面的に譲歩する(4 件)

**(a) 「0.95 閾値は単一評価ログへの後付け」——A の攻撃 3 は正しい。V8 が実証した。** 再集計したのは HF の同一ログであり、独立でも両ランタイムでもなかった。0.95 は撤回する。

**(b) 「label-by-construction 違反」は概念の混同——A の指摘は正しく、しかも私の側の帰結を強める。** provenance ラベルは構成上正しい。壊れているのは**それを観測入力からの予測ターゲットに採用したこと**。この訂正は修正先を生成器から GT 定義へ移すので、A の「再生成 10 時間」ではなく私の再ラベル案(GPU ゼロ)を支持する方向に働く。

**(c) 「必ず」「確実に」の過剰断定——正しい。** 確信度 70% と両立しない断定法だった。撤回。

**(d) 「生徒 ID は開始前なら無料」——正しい。** 同意・仮名化・アクセス制御等のコストがあり無料ではない。必要なのは仮名化された学習者/収集セッションキー。

### 1.2 認識論的地位のみ譲歩し、実務上の結論は防衛する(2 件)

**(e) 上限計算。** V9.3 の注記(条件付き上限であり情報理論的上限ではない)を全面受諾。「モデルは既に天井にいる」は撤回し「3 桁一致は下位区分の割当が純粋なタイブレークであることの強い整合性証拠」に置換。**しかし実務上の結論は生き残る**: A 自身の緩い上限 0.8468 も 0.85 を下回る。どちらの計算からも「9 クラス 0.85 は到達不能」は出る。

**(f) 「0.85 は自明に充足されて KPI が死ぬ」はランタイム限定でしか正しくなかった。** llama.cpp 0.852 は余裕 0.002 で死んでいない。過剰一般化を撤回。

### 1.3 防衛する主張

**(g) 積ペアについて A の D4 は V6 によって反駁された。** A の「非同値 493 件・57.7% の信号を無検証で捨てるな」は、V6 により「425 件の生成器規則の暗記で満点が取れる偽の識別可能性+68 件の真の信号(8.0%)」に分解され成立しなくなった。同時に、混合分布上の平均 ρ に閾値を置く枠組み自体が誤りで、A の D4 も私の R1 も同じ誤った量に乗っており V6 が両方を無効化した。

**(h) 攻撃 7(criterion 2 は集合レベル述語)は反駁されていない。** A の R2 D1 の `repeated` は誤り集合上の述語であり、A の D5 の分割原理を一貫適用すれば集約側に行くほかない。

**(i) 攻撃 3(妥当性の項の欠如)は生きている。** 移項ペアで人間が到達しうる BACC 上限は 0.5×0.956+1.0×0.044=**0.522**。一致率 0.80 は完璧な採点者でも到達不能。第 2 階層再昇格条件には κ に加えて構成ラベルへの BACC を必須にする。

**(j) ③は V7 で確認。ただし帰結は「統合対象にしない」で A と一致(理由は異なる)。** 1.3% のためにファミリ統合は破壊的。クラス単位統合ではファミリ間衝突を原理的に扱えず、扱えるのは領域単位の再ラベルだけ。

## 2. 確信度の変更(要約)

- 否定 1(語り注入はショートカット): 70→80→**85%**(V6 が同型ショートカットの実在を示した: q·r>0 の 425 件)
- 9 クラス 0.85 到達不能: **90%**(条件付き上限として。A の緩い計算も 0.85 未満)

- 再ラベルで足りる: **80%(据え置き)**(再ラベル後の実測がまだ無い以上、上げれば (a) の誤りの再演)

## 3. 閾値設計の最終案(3 層)

**回帰ガードは現測定に合わせるのが定義であり、到達目標ゲートは現測定に合わせてはならない**——この区別が A の攻撃への原理的回答。

- **層 0 データ健全性ゲート**(モデル非依存): 識別不能標本に下位区分 GT が付いている件数=0。閾値 1.0 を要求できる唯一の場所。
- **層 1 タキソノミ・ゲート**(HF fp16・固定層化 n=400): 識別可能粒度との完全一致マクロ。数値閾値は測定後に決定。下限条件のみ事前確定: **0.90 未満なら閾値設定に進まず原因調査**。
- **層 2 配備ゲート**(llama.cpp): 絶対値ではなく**ランタイム間差 ≤0.05**+回帰ガード(直近確定値の Wilson 95% 下限)。差ゲートは「配備経路の視覚劣化」と「タキソノミ」の混同を構造的に防ぐ。
- 共通: クラス別 n 併記/n<20 はマクロに全重みで入れない/クラス数の異なるマクロを時系列比較しない(統合後を新ベースラインとして再起票)。

## 4. D1〜D5 最終決定文

**D1-1** 旧第 2 階層を KPI・SFT ターゲット・報酬から外す。ファミリ内混同行列は診断として常時報告、ただし条件付き ρ・識別可能率・クラス別 n の 3 点併記義務。
**D1-2** `errors[].evidence_basis∈{explicit,unknown}` を追加。explicit は合成生成禁止・実答案人手のみ・基底率測定まで KPI/報酬/昇格に不使用・実測 <15% ならフィールド削除。
**D1-3** `repeated` は errors[] に置かず集約出力へ。
**D1-4** 第 2 階層昇格の人手検証は κ に加えて構成ラベルへの BACC を必須(識別不能領域を分母から除外)。
**D2** 部分報酬は現行撤去。識別可能粒度採用時に三値(完全一致満点/粗すぎ=明確に低い部分点/過剰主張=0)へ。恒久撤去とはしない。
**D3** 深刻度は結果由来へ再定義、定義まで unknown。RL 重み使用可否を最優先で確定。
**D4** クラス統合も G3 再生成もせず領域単位再ラベル(積: 362→ファミリ/425→ファミリ(偽識別)/68 のみ下位区分。移項: 731→ファミリ/34 のみ下位区分)。③は文字列一致分を ambiguous として分母除外、ファミリ統合しない。評価は識別可能粒度との完全一致+過剰主張ペナルティ+被覆率併記。数値閾値は含まない。
**D5** type は要素局所・識別可能ラベルのみ。集約診断は先送り。設計書に「復活は中学生書き手調達(collection_plan.md:50、所有者・期日未定)に律速」と明記。

## 7. 残る真の対立と決着証拠

1. **explicit の合成生成**: 実答案 30〜100 枚の誤規則明示率(≥15% なら A、0〜1/30 なら B)。測定可能になるまで「生成しない」(非対称コスト)。
2. **q·r>0 側の識別可能性**: n=400 で sign(q·r) 層化した下位区分正解率比較(>0 で ≥0.95 かつ <0 で ≤0.6 なら B 確定)。
3. **再生成の要否**: 再ラベル後 GT で既存予測ログを再採点(GPU ゼロ・数十分)。マクロ ≥0.90 なら不要。
4. **深刻度の RL 使用**: 製品側決定。
