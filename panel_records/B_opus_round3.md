# パネリストB(Claude Opus)Round 3 最終見解

## 0. 先決条件の順序について〔A のモートへの応答〕

A の「GT 定義の破綻を直す前にすべての測定は無効」——**順序は全面的に認め、スコープは認めない。**

私の Round 1 の Phase 0 パッケージ A〜I にスキーマ修正項目がなかったのは A の指摘どおりで、項目 0 として追加する(`mutation_site` / `causally_affected_nodes` の分離、記号単位 bbox、跨行・複数 bbox、変異前後ノード対応。工数 ~1 人週)。

ただし「**すべて無効**」は過大である。項目ごとに依存関係を確認した:A(教員 QWK ペア分散)、B(数式レイアウト転記正確率)、C(sim2real の CER)、D(text-only プローブ)、E(blind baseline による点数)、G(判定者比較)、I(権利照会)は、いずれも bbox 粒度にも G2 のゲート意味論にも依存しない。無効化されるのは F と H の**位置報酬に依存する部分だけ**である。修正が 1 人週で並行実行可能である以上、実務上の帰結は「項目 0 を先頭に置く」であって「パッケージ全体を待機させる」ではない。

## 2. 防衛する主張(A の反駁後も残るもの)

### 〔(a)〕KPI 表の欠陥は「算術矛盾」ではなく「尺度の非可換性」である

第一に、BACC の使い方を訂正すると下限シナリオは悪化する:幻覚誤り率 ≤5% は TNR ≥0.95 を含意し、BACC 0.85 は **TPR ≥0.75** を意味する。再計算:1 誤り 0.48、2 誤り 0.23、全体 **0.534**。

第二に、モート2(√QWK 上限)との適用範囲は重ならない:点数完全一致率 80% はノイズなし構成 GT に対して測るため √r 上限は適用されず、QWK 系はノイズある教員参照に対して測るため上限が付く。

第三に、**KPI 表の合成行と人手行は参照系が異なり可換でない**。合成行を全て満たしても人手参照行について何も言えず、製品としての主張を支えるのは人手参照行だけである。**合成 KPI は「開発内部の回帰検知指標」、人手参照 KPI は「主張可能な性能」とラベル分けし、前者を後者の代理として報告することを禁じる。**(85% で維持)

### 〔(c)〕非劣性検定は採るが、参照点を √r に置く

4 名 6 ペアの QWK が独立 6 標本でないことは A が正しい。撤回し、交差ランダム効果(または再標本化)を採用する。ただし教員間一致 r への非劣性検定は、完璧なモデルが √r で通過する「楽に通る」試験である。**参照点を √r に置き、達成率(モデル×教員一致 ÷ √r)を主指標にする。**4 名要求は維持——理由は「6 独立標本」ではなく「**交差モデルで採点者分散成分を同定するには採点者水準 3 以上が必要**」(2 名では構造的に識別不能)。

### 〔(i)(d)〕凍結手順は判定者が誰であれ必須。判定者選択は「推奨」に格下げ

A の凍結・ハッシュ公開・単回評価は CI 境界検査より厳密に優れた統制であり採用する。しかし A は便益を数量化しておらず、判定者の優劣は予算内で実証できない(対応設計でも ±6〜7.5pt、±3pt には 600〜700 件=人手上限を単独で食い潰す)。**便益差が測定不能なとき、リスクの低い方を選ぶ**:自前ホスト V4-Flash 推奨(必須ではない)。A の「異系列でも文体・長さ等の選好バイアスは残る」は正しく、私の DeepSeek 案にも等しく当たる——**設計書 §2-4 の「構造的に回避」はどの判定者でも偽**であり、これは双方が設計書に立てるべき指摘である。

### 〔(e)〕購入案の撤回と、その裏付けの数値化

注釈費計算(上表)は、購入が代替でないことを数値で確定させる。設計書が書き換えるべきは路線ではなく**根拠**であり、正しい根拠は「細粒度・反実仮想ラベルは購入経路では注釈費が支配的になり、合成の方が安い」。これは設計書の主張に初めて数量的裏付けを与える。

### 〔(g)(j)〕診断の設計——A の対案+二点

A の複数ベースライン(画像ブランク/画像シャッフル/ラベルシャッフル/問題文のみ)を採用、AUC>0.7 閾値は撤回。追加:(1) **容量整合対照**——同サイズのテキスト専用モデルを同一データで SFT し、VLM が上回るかを見る(2B で 1 日、最も安く決定的)。(2) **入力契約を Phase 0 の成果物にする**。さらに設計書内部の具体的不整合:§M4 の訓練入力は step_id 付き gold_solution を含むが、§M5 の実データ側で参照できるのは answer_key(最終解)のみ——誤り位置報酬の「ステップ ID 一致」の参照先が実データに存在しない。入力契約は未決なのではなく、文書内で二通りに書かれている。

### 〔(h)〕三条件分離を採用+決定規則

オラクル転記=「正しく読めた場合に良い指導文が書けるか」/学生転記=「見たと信じた内容と整合しているか」/画像込み人手=「生徒に出して安全か」。**三条件は別々に報告し決して集約しない。製品としての主張を支えるのは第三条件のみ**(n≈150〜200 の安全スクリーンとして報告)。

### RLVR:最終形は三点セット

(i) 一次選定=合成 held-out 5,000 件(相対順位のみ)、(ii) 実筆跡=符号チェック(反転の有無のみ)、(iii) **報酬関数の敵対的テスト**(A の n=1,000・不正出力優位率 <1% は、A の反証条件の中で唯一標本サイズが閾値に見合っている。Wilson 上限 1.9%)。診断スイート(2B 単項目 run×7=56 GPU 時間)は 8B 1 run(2,688 GPU 時間)の 2% であり、1 回の無駄な 8B run を防げば元が取れる。

## 3. 三争点の最終立場

(1) **筆跡セット**:総計 ~1,350 枚(書き写し 900 item-disjoint/公平性 330=30 書き手×11 共通内容ラテン方格/自力解答 ~120=訂正行動の定性インベントリ)。書き手・ページは用途間で完全分離、レンダラ校正は別パイロット。増分 ¥80〜100 万。枚数を上げないなら KPI を片側の壊滅スクリーンへ。

(2) **LLM 判定者**:凍結・ハッシュ公開・単回評価を必須化(判定者が誰であれ)。判定者は自前ホスト V4-Flash 推奨(必須→推奨に格下げ)。GPT-5.6 を選ぶ場合は便益の 1 段落文書化。判定者比較は n=100 の粗大差スクリーンに留める。三条件分離。

(3) **実データ**:A の月 2 LOI ゲートを全面採用。ゲート判断に注釈費計算を含める(購入が代替でないことを数値で確定させ、以後の再燃を防ぐ)。

## 5. 残る不確実性

1. **教員間一致 r の実測値**——最も安く、最も早く測れて、最も多くを決める未知数(4 名×100 件・1 名 8 時間)。r<0.5 なら点数の製品主張自体が成立しにくい。
2. 成人書き手の自力解答が生む誤り分布(10 名×8 枚のパイロットで誤り種別分布を記述すれば判定可能)。
3. 権利照会に回答が返るか。返らなければクリーンルーム正系統化に収束し、筆跡 1,350 枚は評価資産兼字形バンクとして二重に回収される。
4. **合成閉ループからの脱出方法は本計画の設計では解消されない**——両パネリストの議論から出た最も堅い結論。条件 4 の「代理報告の禁止」が最大リスクへの唯一の実効的防御である。
