# Round 3 — 最終立場(パネリストB)

## 0. 結論(先出し)

Round 3 で私の立場は**一点で構造的に変わった**。Round 1 で私は「無料の下流ゲートを先に置け」と主張したが、Aの§2(代理性)批判を検算した結果、**私が提案した下流ゲートは下流ゲートではなかった**。社員模擬答案では、私自身が最大寄与項に置いた (d) 内容分布・(c) 行動的レイアウトを一切標本していない。したがって:

> **Phase 0 には、現時点で有効な採点KPIゲートが一つも存在しない。** 設計書にもないが、私のRound 1対案にもない。Aが§1で正しく述べた「座標ゲートと下流ゲートは直列で両方必要」という構造において、**直列鎖の下流端は誰も建設できていない**。

この事実は、AとBの技術論争18項目+私の9節すべてより上流にある。よって最終勧告の第1位は diffusion でも ETL でもなく「実生徒答案の最小獲得」になる。

diffusion 層をクリティカルパスから外すという中心的主張自体は**維持し、確信度を上げる**(72%→78%)。ただし根拠は Round 1 の「無料アブレーションで不要が確定するから」ではなく、**Round 2 で私が自己訂正したスループット(33,000 GPU時間)と、その帰結としてAが要求する識別実験自体が Phase 0 予算で実行不能である**ことに置き換わる。

## 2. 全面譲歩

- **2-1. 社員模擬答案は「実答案評価セット」ではない(私のRound 1最大の欠陥)**: 自分の因果モデル(内容・行動分布が最大寄与)と自分の測定計画が矛盾。40人時の脱落も認める。再スコープ: 「実インク可読性プローブ」に降格(既知文書写でGT構成的確定、転記CERのみ正当測定)。「最高期待値の一手」80%→35%。
- **2-2. 3系統アブレーションは diffusion の必要性を識別しない**: diffusion 群が存在しない。「差3pt未満で不要が確定」は完全撤回(→0%)。生き残るのは「外観軸の局所勾配測定」という降格版のみ。
- **2-3. ETL「筆者200名」**: 設計書の未確認仮定を事実として使った。撤回→計数タスク化。
- **2-4. 「情報量ゼロ」「Kondateのみ」「100組60:40」**: いずれも撤回。正確には「教師P(A)には実答案固有情報が追加されない」(Aの定式化を採用)。P外教師は社員/実収集手書きも該当。リアリズム2択は目的と無関係な検定だった。

## 3. 部分譲歩(算術受諾・推定量訂正で救済)

- **3-1. ICC批判**: 絶対率には正しいが、決定量は同一評価セット上の対応あり差。McNemar で n=1,000・不一致率20%なら差の半幅±2.7pt、10pt検出可。外的妥当性批判(10名→生徒)は§2-1で譲歩済み。
- **3-2. AUC±0.03はアンダーパワー(受諾)**: 検定を「No-Goトリガ専用(AUC≥0.60)」に非対称化し、clearance には使わない。パッチ単位測定へ変更(700組=1,400パッチ=13〜18GPU時間で実行可能——ページ単位なら130〜175時間で不能)。Edit前ベースライン必須(A§4受諾)。双子漏洩の確信度 65%→60%(現行レンダラに元から漏洩があり diffusion への帰属確率が下がる)。
- **3-3. 棄却率差2ptに4,802件は独立比率の話**: ペア設計なら π_d=0.05 で480ペア。ただし π_d を置いていなかったのは私の過失。二段設計(第1段200組で π_d 実測)に変更。
- **3-4. 「無条件本線」は誤読(受諾)**: ただし訂正すると批判は強くなる——**Stage A の Go/No-Go に費用条件が入っていない。費用条件を持たない条件付きゲートは費用に関して無条件承認と等価**(95%)。修正は設計書1行(総GPU時間≤150h の追記)。

## 4. 防衛する主張

- **4-1. diffusion 層はクリティカルパス外へ(72%→78%)**: (1) 強制1MPリサイズ→パッチ分割で費用が下がらない、25〜41s/パッチ、30万頁≈25,000〜37,500GPU時間(自己訂正)。(2) A自身の式で150h未満は f<0.005(全頁の0.5%)。(3) 【新】Aが要求する識別実験自体が100〜300GPU時間=Phase 0 予算超。論理形式: **必要性を検証する費用が検証対象の期待価値の上限に近い介入は、クリティカルパスに置いてはならない**。反証条件: s/パッチ実測で s<1.0(推定の1/30)なら負け(ComfyUI前処理経路が未検証なのが私の急所)。
- **4-2. 位相相関不適合(80%→85%)**: Aも同意。
- **4-3. Stage C 削除(90%→72%)**: Aの「LoRAは条件追従/グリフ保存という信頼性軸を改善し得る」は正当な打撃(私の未考慮機構)。それでも削除を推す新定式: **Stage C を信頼性で正当化すると成功の極限は B' 出力そのもの(成功指標と目的の背反)**。P外教師が要る→Kondateは持ち出せない→実収集は評価計器の材料として優先。反証条件: 500ペアLoRAがゼロショット比で追加CER半減∧ドリフト中位値半減なら「信頼性工程」として復活。
- **4-4. 検品=選択バイアス装置(85%不変)**: 盲点相関のみ50%へ下げ(「同じQwen系」は相関量の証拠でない)。
- **4-5. AのIoU≥0.9×99%閾値は達成不能(90%)**: 再検算一致。較正代替: 報酬実使用閾値で95%+判別AUC<0.60。
- **4-6. ETL三分割ゲート(照会即日/開発継続/配布のみゲート)を維持(45%)**。
