# 敵対的パネル統合所見: T2I 化・FT 検討書(docs/t2i_handwriting_plan.md)

実施: 2026-08-17。パネル構成: A=Codex(codex-cli 0.144.1、外部CLI・検証再実行担当)/B=Claude Opus(Agent model=opus、第一原理・外側視点担当)。異種モデル×異種方法論の Tier-1 構成、3ラウンド+ファシリテータ裏取り(ETL規約原文・DiffSynth train.py・diffusers パイプライン実装・m3_render.py 実コード)。決定的数値はファシリテータが全て再計算済み(IoU境界・rule of three・スループット・ペア検定CI: 全一致)。討論記録は panel_records/t2i_*.md。

## 合意点(異種パネル・全会一致=強い収束)

1. **Edit 変換後の系列は label-by-construction ではない**。正確には label-by-OCR-screening。`label_by_construction` フラグで主系列(Stage B'+撮像層)と Edit 系列を隔離する(A発案、B「単独最良の貢献」と評価)。
2. **Stage B' 自体も現行実装のままでは「完全保存」でない**。必要修正: (i) mask 由来の bbox 再計算(質量ベース: bbox+マージンがインク質量99.9%以上)、(ii) `_union` の右下端 ceil 化、(iii) **文字IDベース乱数**(現行は変異点以降で双子のジッタ列・折返しがずれる=コード照合で確定)、(iv) 欠字 fallback の provenance 記録、(v) **ETL9G(128px・4bit階調)を 9B(64px二値)より優先**、(vi) ETL9 の writer 対応・OOV(数字・英字・カタカナ・数学記号は ETL9 に無い)を全レコード走査で実照合。
3. **30万頁全体への diffusion 適用は経済的に不能**。diffusers 実装は入力を面積1024²へ強制リサイズ(スキップ分岐なし)するため、行パッチに分割しても1枚あたり計算量は下がらない。T4 実効で 25〜40秒/パッチ → 30万頁×10パッチ ≈ **3万GPU時間**(Kaggle 週30hで約19年分)。Stage A の Go/No-Go に**費用条件(実測 s/パッチからの外挿総GPU時間 ≤150h 等)を追加**する。diffusion は少量高級品工程(評価セット・一部多様化)としてのみ成立。
4. **位相相関補正は大域平行移動のみ**で、非剛体ドリフトの文字単位補正には原理的に不十分(両者独立に同結論)。
5. **OCR/VLM 検品ループは選択バイアス装置になりうる**: 判定器が読める崩れしか残らず乱雑さの裾を選択的に除去、編集モデルの「正しい文字への修復」傾向により棄却が誤り側に偏る恐れ(B 75%)。人手監査(採択400/棄却100の粗監査)+誤り/清書・画数・乱雑度層別の棄却率監視を必須化。false accept 0.1% の保証には採択3,000件必要(rule of three)。
6. **双子ショートカット漏洩の検定は Edit 前ベースラインとの増分で行う**(現行レンダラに元から乱数 desync 由来の漏洩があるため、絶対値では diffusion に帰属できない)。検定は No-Go トリガ専用(AUC≥0.60 で No-Go)とし、AUC≈0.5 を「漏洩なし」の証明には使わない(±0.03 の clearance には各側~712件必要)。
7. **ETL 法務**: 規約原文(2025-03-28版)は目的制限なし・無料、禁止は「データ自体の配布」のみ、**派生物(LoRA・合成画像・クラウド処理)は未規定**。→ 社内 B' 開発は止めない/AIST 照会(3点明記)を即日送付/社外配布局面のみ回答待ちでゲート。
8. **Stage C(自給ペア LoRA)は Phase 0 から凍結**。理由: (a) 教師が自前手続き P の出力である限り実答案固有情報は増えない(「情報量ゼロ」は過剰表現とBが撤回、正確には「P外情報の非追加」)、(b) Kondate は購入(50万円)しても敷地外持ち出し制限がありクラウド学習と衝突。復活条件は「P外教師画像の確保 ∧ ゼロショット比で追加CER半減かつbboxドリフト中位値半減(信頼性指標)」。
9. **図形の「意味レベルだから低リスク」は誤り**: グラフの傾き・交点・目盛、幾何の平行・直角、筆算の桁位置は局所幾何そのものがラベル。xkcd は `sketch_params` の scale を既知上界とし「GT=意図座標±scale」の有界膨張として扱う。
10. **事実誤記の訂正**: `--zero_cond_t 1`→`--zero_cond_t`(store_true)、「16の倍数・~1MP以内で恒等」→「面積≒1024²・32倍数の不動点寸法でのみ恒等、~1MP未満は拡大される」、2511公開日 12-23、GGUF はコミュニティ量子化。
11. **下流KPIゲートの欠如が設計書と両パネリスト初期案に共通する最上流の欠陥**。座標ゲートと下流効用ゲートは直列で両方必要(A)。ただし社員模擬答案は実生徒の内容分布・行動的レイアウトを標本しないため「採点KPIゲート」ではなく「実インク可読性プローブ」(既知文書写で転記CERのみ測る)に降格(B自身が譲歩)。**実生徒答案の最小獲得(30〜50枚)を Phase 0 ブロッカーに格上げ**するのが B の最終最優先勧告で、A の勧告3(実対象評価セットの先行確保)と整合。

## 対立点(裁定つき)

- **Stage A の位置づけ**: B「クリティカルパス外(78%)。識別実験(diffusion アーム比較)自体が100〜300GPU時間で Phase 0 予算を超えるため最後尾」/A「下流KPIゲート先行には同意(98%)だが、diffusion 群なしの比較で diffusion 不要は確定できない。B' 不足時のみ Stage A PoC」。→ **裁定: 実質同一の順序(B'修正→下流評価→不足時のみ Stage A)に収束済み**。残る差は着手条件の厳しさのみで、意思決定を変えない。安価な s/パッチ実測(1〜2GPU時間、Bの反証条件)だけは早期に実施してよい。
- **アブレーションの検出力**: A「±3pt CI は独立仮定、ICC=0.05 で±7.6pt」/B「決定量は同一評価セット上の対応あり差なので McNemar で±2.7pt(n=1000, 不一致率20%)」。→ **裁定: 両方正しい(対象が違う)**。モデル間比較は対応ありで n=1,000 で成立(B)、10筆者→生徒母集団への外的妥当性は別問題として残る(A、Bも譲歩)。ファシリテータ再計算で両者の数値とも再現。
- **生成器×判定器の盲点相関(Qwen-Edit×Qwen3-VL)**: B は機構主張を 50% に下げた(A「同系列は相関量の証拠でない」)。→ **裁定: 未解決・実測可能**。棄却200枚の人手分類(4〜6人時)で決着。安価なヘッジとして独立系 OCR の併用を推奨。
- **A の Round-1 合格閾値(IoU≥0.9×99% 等の連言)**: B「原理的に達成不能(τ=0.9 は実寸 box で許容ずれ1.5〜2px、10×10記号で0.27px)」→ A 自身が Round 3 で撤回。→ **裁定: B の較正代替を採用**——「補正後誤りスパン box の95%以上が報酬実使用 IoU 閾値(0.5)を維持」+「残差ずれの誤り/清書判別 AUC<0.60」。

## 結論

**設計書は「条件付き採用+大幅修正」。** 生き残った骨格: グリフ保存スタイル変換>プロンプト直接生成、Qwen系(Apache-2.0)、ETL グリフバンク、回答領域パッチ方式、検品ループの必要性。パネルが killed した主張: 「3層防御で label/bbox/双子を保存」(→Edit系列は by-construction でない)、「~1MP以内・16倍数で恒等」(誤り)、「同一seedで双子同一」(保証なし+現行レンダラも既にずれる)、「図形は低リスク」(誤り)、「Kondate で上位LoRA」(持ち出し制限)、30万頁本線適用(経済的に不能)、Stage C 自給ペア(P外情報なし)。

パネルが新たに生んだ発見(どちらの Round 1 にも無かったもの): (1) 強制1MPリサイズの**スループット爆弾**性(パッチ分割が費用を下げない)、(2) A の合格閾値の原理的達成不能性、(3) 現行レンダラの双子 desync(全検定の対照群設計を変えた)、(4) 「Phase 0 に有効な下流計器が存在しない」という最上流欠陥と実生徒答案30〜50枚の最優先化、(5) ETL9 の writer 対応が未照合の仮定であること、(6) ETL9G 階調が「diffusion が唯一埋める筆致テクスチャ」を無償供給する構図。

パネル構成の較正注記: 異種モデル(GPT系CLI+Claude Opus)・異種方法論で、技術的事実の収束は強い証拠。ただし両者とも同一の設計書全文を読んでいるため、問題フレーミング自体への収束(例: Qwen系という選択自体の妥当性)は割引いて読むこと——「そもそも diffusion をやめる」選択肢は B が独立に提起し生き残っている。
